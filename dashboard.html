HOW THIS WAS BUILT

Two raw sources, both one export per match: shot-level SwingVision-style exports (one row per ball) and point-level Hawk-Eye exports (one row per point). Each player's panel pools every tracked match they have. Serve, serve+1, rally length and point endings are computed the same way from both; net and return depth exist only in the shot-level source, so they are shown only where the underlying data supports them. Counts are shown next to every rate because most samples are one or two matches.
