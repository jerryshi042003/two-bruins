HOW THIS WAS BUILT

Source data is the raw SwingVision match export for each singles match — one row per ball struck, carrying stroke, spin, speed, direction, result, contact and bounce coordinates in metres, and the position of that shot in the match video.

Shots are mirrored into a single court frame so every hitter attacks in the same direction, then converted into the court units used by the Bruin Tennis Consulting analytics library (1 m = 38.28 units, net at zero) so the existing D3 court visuals, zone splits and Win% / Freq badges apply unchanged. Point outcomes are derived from the final ball of each rally. Percentages carry their sample size because several of these splits rest on fewer than twenty serves.

No manual tagging was added. Everything here comes out of the SwingVision file itself.
